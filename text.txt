Resumen

Se restauró el flujo completo: login → sync usuario → crear publicación (wizard original) → visualizar en Home.
En el Home ahora se ve el nombre del autor de cada publicación.

Qué funciona hoy

Auth + Sync: tras login se hace POST /api/users/me y se asegura /users/{uid} en Firestore.

Publicar: wizard “¿Qué le ofreces a SkillSwapp?” → POST /api/publications (token Firebase) → 201.

Feed: GET /api/publications (activo=true, orden desc) muestra la publicación recién creada.

Cambios clave

Frontend usando servicios que llaman al backend (no Firestore directo) para publicaciones.

CORS y headers Authorization configurados.
